# 🖼️ Discord 画像圧縮くん

Discord無料プランの添付ファイル10MB制限に向けた、画像圧縮Webアプリ。
**完全ローカル処理**（サーバー不要・ファイル送信なし）。

## ✨ 機能

- 📎 ドラッグ&ドロップでアップロード
- 🎯 10MB以下に自動圧縮（二分探索でギリギリまで画質を保つ）
- 🗑️ EXIF/メタデータ全削除
- 📐 自動解像度ダウンスケール
- 📦 WebP / JPEG / PNG 切替可能
- 🔒 完全ローカル処理（サーバー通信ゼロ）

## 🚀 使い方

[GitHub Pagesのリンク](https://moruton1119.github.io/discord-image-compressor/) にアクセスするだけ！

## 🛠️ 技術構成

- HTML + Vanilla JS（依存ライブラリゼロ）
- Canvas API（圧縮エンジン）
- GitHub Pages（ホスティング）
